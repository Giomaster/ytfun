Privacidade e dados

Informações sobre os dados utilizados pelo aplicativo AI Meow e como solicitar sua exclusão.

O AI Meow utiliza o estúdio ytfun para planejar, produzir e distribuir conteúdo original gerado com inteligência artificial nos canais e Páginas autorizados pelo operador.

Política de privacidadeQuais informações são utilizadas, como são compartilhadas e quais controles estão disponíveis. Exclusão de dadosComo fazer uma solicitação, revogar uma conexão e distinguir dados locais de publicações nas plataformas.

Sobre a hospedagem destas páginas

Estas páginas são arquivos estáticos, sem scripts, formulários, cookies ou ferramentas de análise adicionados pelo AI Meow. Estas páginas são hospedadas no GitHub Pages. O GitHub registra o endereço IP dos visitantes para segurança e pode processar outros metadados de acesso conforme sua Declaração de Privacidade. Consulte também a documentação de coleta de dados do GitHub Pages.
